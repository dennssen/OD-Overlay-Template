# Contributing to OverlayWebsite

We welcome contributions from the community! Here's how you can help:

## Reporting Issues With Templates
- Search existing issues before creating a new one
- Provide detailed information:
  - Steps to reproduce
  - Expected vs actual behavior

## Making Contributions
Want to add a new template, or perhaps fix an old one? Just follow these steps:
1. Fork the repository
2. Create a branch for your feature/fix
3. Commit your changes
4. Push to your fork
5. Open a Pull Request (PR)

## PR Guidelines
- Reference related issues in your PR description
- Keep changes focused on a single purpose
- Follow the project's coding style
- Update documentation if needed

## Code Review Process
- Maintainers will review your PR
- You may need to make changes based on feedback
- Once approved, we'll merge your contribution!
