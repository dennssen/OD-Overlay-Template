# OverlayWebsite
OverlayWebsite is a website that contains template overlays to be used in casting for Orion Drift.

## Installation
To install the templates for personal use press the green code button and then `Download ZIP`. Once the `.zip` file is downloaded extract the files anywhere on your computer.

Now the templates are installed and available locally.

## Get started
With the templates on your computer you can now start using the overlays. To get a quick look over all the available templates open the `index.html` file in the `Webpage` folder. In the `index.html` page you can also find a Help page that answers questions related to the templates.

For actually displaying the overlays in a recording or a live stream i recommend using Browser sources in OBS and ticking the `Local File` checkbox.
