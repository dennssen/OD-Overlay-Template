Title: OverlayWebsite
**OverlayWebsite** is a website that contains template overlays to be used in casting for Orion Drift.

**Installation**
To install the templates for personal use download the `Template.zip` file in this thread. Once the `.zip` file is downloaded extract the files anywhere on your computer.

Now the templates are installed and available locally.

**Get started**
With the templates on your computer you can now start using the overlays. To get a quick look over all the available templates open the `home.html` file in the `Webpage/Home` folder and navigate to Overlays. In the `home.html` page you can also find a Help page that answers questions related to the templates as well as some API info.

For actually displaying the overlays in a recording or a live stream I recommend using Browser sources in OBS and ticking the `Local File` checkbox. More info is available in the Help page.

**Help & Questions**
If you have any questions or need any help with setting up or creating your own overlays then you can reach out to dennssen on discord or ask your question in the overlay forum in the spectator forums.
