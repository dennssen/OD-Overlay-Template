Help

This page contains a list of questions and answers that will help you understand how these overlays work and how to use them.

How does it all work?

The overlays are created using completely basic html, css, and javascript. They then fetch data from both Orion Drifts API and the overlayInfo config file. Using this data the overlay gets filled with relevant info about the match the caster camera is currently watching.

What is the overlayInfo script for?

The luau script named "dennssen.overlayInfo.luau" is crucial to make overlays work. The overlayInfo script is in direct contact with the caster camera script. This lets the overlayInfo script communicate with the overlay by saving values to its config file about what the caster camera is doing such as, what arena it has selected, who is playing in the arena, is the caster camera following someone, data about the last goal, players stats gathered throughout the game, etc.

How do I set up the overlays?

For the overlays to work you will need to have the Orion Drift Spectator client open, as well as having both the caster camera and overlayInfo script installed. Once you've gotten the spectator client ready add the overlays to OBS using Browser sources and add your local overlay html file. If you are having trouble with the overlays not updating make sure that you have turned on "Send info to overlay" under the "Overlay" dropdown in the caster camera settings.

How do I set team name and logos

To set a team name go to the caster camera settings and navigate down to the "Overlay" dropdown. Once opened there should be a "Home Team Name" and an "Away Team Name" text input field. Put in the names of the respective teams and press the "Send info to Overlay" button. This will send the team names to the overlay for it to display.

For team logos it depends on which overlay you are using, but for the template overlay you will need to have the logo downloaded locally and placed in the scoreboards "Assets/Images" folder. Then the image will have to follow these rules for it to be loaded by the overlay.

  • The image has to be a .png
  • The image has to be named after the teams name
  • The image name has to be all lowercase
  • The image name has to use underscores (_) instead of spaces
  • Example Team Name: It's My Team Name
  • Example Team Image Name: it's_my_team_name.png

If all the rules are followed the teams logo will load in automatically once the teams name is in the overlay.

How can I make my own overlays?

Creating your own overlays is quite simple with some prior knowledge with html and javascript. All the template overlays are completely open-source under the MIT license, this allows you as a developer to use the templates for inspiration or use the templates directly with your own modifications. The templates are made to be learned from, with clear nameing and some comments in the javascript. If you have any questions about how to make your own overlay you can reach out to me through discord (dennssen) or ask your question in the overlay thread in the Orion Drift discord.
