Setup Help

Help and info regarding how to setup and use overlays.

What do I need for overlays to work?

For the overlays to work you will need to have the Orion Drift Spectator client open, as well as having both the caster camera and overlayInfo script installed. You'll also need something to display the overlay with. I recommend using OBS.

How do I setup overlays in OBS?

In OBS create a new scene and call it whatever you want. Under sources for that scene you'll need to add a Browser source. When setting up the Browser source make sure to check the "Local File" checkbox, then navigate to the .html file of the overlay you want to display. You can have multiple Browser sources in the same scene so mix and match however many overlays you want to fit your style.

How do I use the overlays?

Once you have your overlays setup in OBS they will use the info from the selected arena in the caster camera. When casting actual teams you'll usually want their team names in the overlay. You can set the teams names for home and away in the caster camera UI under Overlay. When everything is set the overlay will update everything automatically.
