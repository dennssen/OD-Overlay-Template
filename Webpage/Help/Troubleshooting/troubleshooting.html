Troubleshooting Help

Help and info regarding how to troubleshoot overlays.

My overlays are not updating.

If your overlays are not updating make sure you have the spectator open, that you have the correct arena selected, that the overlayInfo script is installed, and that you have "Send Overlay Info" checked in the Overlay settings for the caster camera. If you are still having trouble try restarting Orion Drift and OBS and refreshing the Browser source.

Parts of the overlay gets cut off in OBS

If your overlay gets cut off in OBS it is usually the custom CSS from OBS causing the issue. Right click the respective Browser source and press properties. Make sure that the custom CSS does not contain "Overflow: hidden;".
