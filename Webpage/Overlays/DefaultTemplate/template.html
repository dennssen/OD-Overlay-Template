Default Template

The Default Template overlay is an overlay with mostly placeholder assets designed to be a last minute option for someone looking to use overlays or a way to teach developers how to make their own overlays.

/Info

Some info about setup and use of this overlay.

/scoreboard

An overlay for the scoreboard. Shows teams, scores, rounds and gametime.

/gameinfo

An overlay that shows info about the game outside of the scoreboard. Players, goals, etc.

/stats_showcase

An overlay for showcasing the game stats. Shows stats for each player and the scores for each round.
