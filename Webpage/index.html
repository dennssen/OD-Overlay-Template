Overlays

This page contains a list of overlays and templates. The overlays and templates on this page are all open source and can be edited and used for personal and commercial use.
More overlays and templates may be added in the future.

/gameinfo

An overlay/template that shows info about the game outside of the scoreboard. Players, goals, etc.

/stats_showcase

A page for showcasing the players stats for the game. As with the full template this is also a template that you can use for learning how to make your own, as well as it being available as is to use for yourself without having to make your own.

/API_Examples/extraArenaInfo

An example file of how the json structure from the overlay info script is. Contains more info about the selected arena you are unable to get from the normal spectator API. Helpful for testing overlays without the spectator client open and understanding the API.

/API_Examples/statsInfo

An example file of how the json structure from the overlay info script is. Contains info about each players stats from the last/currently played game. Helpful for testing overlays without the spectator client open and understanding the API.
