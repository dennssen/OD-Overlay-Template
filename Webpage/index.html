Overlays

This page contains a list of overlays and templates. The overlays and templates on this page are all open source and can be edited and used for personal and commercial use.
More overlays and templates may be added in the future.

/scoreboard

An overlay template for the scoreboard. Shows teams, scores, rounds and gametime.

/gameinfo

An overlay template that shows info about the game outside of the scoreboard. Players, goals, etc.

/stats_showcase

An overlay template for showcasing the game stats. Shows stats for each player and the scores for each round.

/API_Examples/extraArenaInfo

An example file mimicing the structure of the extraArenaInfo gotten from the dennssen.overlayInfo.luau script.

/API_Examples/statsInfo

An example file mimicing the structure of the statsInfo gotten from the dennssen.overlayInfo.luau script.
